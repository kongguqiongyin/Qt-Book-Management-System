# 📚 Qt Book Management System (图书管理系统)

这是一个基于 **C++** 和 **Qt框架** 开发的桌面端图书管理系统。该项目旨在提供一个简洁、高效的界面来管理图书信息，适合用于课程设计、C++学习参考或小型图书馆管理。

## ✨ 主要功能

- **图书录入**：支持添加新书籍信息（书名、作者、ISBN等）。
- **信息查询**：快速检索库藏图书。
- **数据管理**：支持对图书信息的修改与删除。
- **持久化存储**：使用文件流（fstream）或数据库保存数据，重启后数据不丢失。
- **跨平台潜力**：基于Qt开发，理论上支持Windows/Linux/macOS（目前主要在Windows下测试）。

## 🛠️ 技术栈

- **编程语言**: C++ (C++11/14/17)
- **GUI 框架**: Qt (Qt5 / Qt6)
- **开发工具**: Visual Studio / Qt Creator
- **构建系统**: QMake / CMake
